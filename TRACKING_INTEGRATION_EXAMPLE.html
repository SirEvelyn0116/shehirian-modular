How it works:

  1. User clicks recipe card → Click event captured by recipe-click-tracker.js
  2. Tracker extracts slug → From href pattern (e.g., "royal-soup" from "royal-soup.en.html")
  3. Sends to serverless endpoint → POST to your deployed Lambda/Azure/Firebase function
  4. Counter incremented → serverless/data/counters.json updated with click count
  5. Run updateFeatured.js → Marks top recipe per category (soup/main/dessert) as featured
  6. Rebuild site → Featured recipes now highlighted automatically

NPM Scripts Available:

  • npm run track:test - Start local test server (port 3000)
  • npm run track:update-featured - Update featured recipes based on clicks
  • npm run track:view-counters - View current click counts
  • npm run track:backup - Create backup of all-recipes.json
