# Traditional-name candidates for the Shehirian brothers

Standing, accumulating list of recipes that may be anglicized/adapted versions of dishes with
an authentic traditional name, flagged **tentatively** for the brothers to confirm and, if they
choose, supply the authentic name/spelling themselves. This is identification only — no renames,
no content changes, and no guessed transliterations (a guessed spelling would be worse than the
current English name). Confidence is stated honestly; several entries below are "skip" calls
recorded for completeness, not real candidates.

kneaded and shaped into patties, served the same day — reads as an anglicized çiğ köfte / "chee
kufta." See `altered-recipes-discrepancy-log.md` for detail; not repeated here since it's outside
this pass's page 4–6 scope.
